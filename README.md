# AI Study Assistant

A Python-based AI study assistant using a locally hosted Qwen model through Ollama.

## Features

- Ask AI questions
- Summarize text
- Generate quizzes
- Multiple-choice, short-answer, and true/false questions
- Difficulty selection
- Automatic scoring
- AI output validation

## Requirements

- Python 3.12+
- Ollama
- Qwen 3 0.6B

## Setup

Install Ollama and pull the model:

```bash
ollama pull qwen3:0.6b
